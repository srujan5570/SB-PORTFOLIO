## ✨ Overview

A modern, animated developer portfolio built with **React, TypeScript and Vite**. It showcases my experience, projects, skills and contact details, with a neon-glass visual theme and motion-driven interactions.

### Sections

| Section | Description |
| --- | --- |
| **Hero** | Animated intro with rotating roles and quick links |
| **About** | Background, education and highlights |
| **Skills** | Tech stack grouped by category |
| **Projects** | Live apps and products with Play Store / website links |
| **Experience** | Internships and professional work |
| **Contact** | Email, phone, location and social links |

The site also ships a **resume page** and a **V-NutriLife product mockup** under `public/`.

## 🛠 Tech Stack

- **Framework:** React 19 + TypeScript
- **Build tool:** Vite
- **Styling:** Custom CSS with glassmorphism and neon tokens
- **Animation:** Framer Motion + React Intersection Observer
- **3D / visuals:** Three.js, React Three Fiber, Drei
- **Icons:** React Icons
- **Deployment:** GitHub Pages

## 🚀 Getting Started

```bash
# install dependencies
npm install

# start the dev server
npm run dev

# production build
npm run build

# preview the production build
npm run preview
```

## 📦 Deployment

The site is deployed to GitHub Pages from the `dist` folder:

```bash
npm run deploy
```

> `vite.config.ts` sets `base: '/SB-PORTFOLIO/'` so assets resolve correctly on GitHub Pages.
